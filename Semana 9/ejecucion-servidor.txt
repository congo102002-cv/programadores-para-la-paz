¿Qué ocurre cuando ejecutas node server.js?
Al ejecutar el comando node server.js, Node.js inicia la aplicación y pone en funcionamiento el servidor. A partir de ese momento, el servidor queda listo para recibir y procesar solicitudes de los usuarios.
¿Qué mensaje aparece en la terminal?
En la terminal suele mostrarse un mensaje similar a: Servidor escuchando en el puerto 3000. Este mensaje confirma que el servidor se inició correctamente y está disponible para recibir peticiones.
¿Qué sucede cuando visitas la ruta /estado?
Al ingresar a la dirección http://localhost:3000/estado, el servidor responde con información en formato JSON que indica que la aplicación está funcionando correctamente.
Ejemplo de respuesta:
{
  "estado": "Servidor funcionando",
  "servicio": "API comunitaria"
}
